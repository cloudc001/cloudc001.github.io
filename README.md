# CloudC EdLab Network

Static introduction page for CloudC EdLab Network / AS203991.

The site describes the network's routing information, peering policy,
operational notes, and public contact points.

## Peering policy

- Public policy page: `peering/index.html`, served at `/peering/`.
- GitHub Pages redirects the PeeringDB policy URL `/peering` to `/peering/`.
- Policy and NOC contact are aligned with the public AS203991 PeeringDB record.
- The page distinguishes public peering, Anycast routing, and the separate DN42 lab.
